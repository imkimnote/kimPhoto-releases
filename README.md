# kimPhoto

사진 보기·편집 프로그램 **kimPhoto** 의 설치 파일을 받는 곳입니다 (Windows 10/11, 64비트).

## 받기

오른쪽 **Releases** 에서 최신 버전을 고르고, 아래 파일 중 하나를 받으세요.

| 파일 | 언제 |
|---|---|
| `kimPhoto-버전-Setup.exe` | **처음 설치할 때** (AI 모델 포함, 약 350MB) |
| `kimPhoto-버전-Update.exe` | 이미 설치되어 있을 때 업데이트 (약 80MB). 맞지 않으면 Setup 을 쓰라고 안내합니다 |

- 관리자 권한 없이 설치됩니다 (`%LOCALAPPDATA%\Programs\kimPhoto`).
- 내려받거나 설치할 때 경고창이 뜨면 아래 **경고창이 뜰 때** 를 보세요.
- 받은 파일이 맞는지 확인하려면 `SHA256SUMS.txt` 의 값과 비교하세요 (PowerShell: `Get-FileHash 파일이름`).
- 업데이트하거나 제거해도 편집한 내용과 설정은 지워지지 않습니다.

## 경고창이 뜰 때

kimPhoto 는 개인이 만든 무료 프로그램이라 아직 **코드 서명(전자 서명)** 을 하지 않았습니다.
그래서 Windows 와 브라우저가 처음 보는 프로그램이라며 아래 경고를 띄웁니다. 프로그램에 문제가 있다는 뜻은 아닙니다.

**1. 내려받을 때 (크롬·엣지)** — "일반적으로 다운로드되지 않는 파일" 경고
- 크롬: 다운로드 목록에서 **[⋯] → [유지]**
- 엣지: 다운로드 목록에서 **[⋯] → [유지] → [자세히 표시] → [그래도 유지]**

**2. 설치 파일을 실행할 때** — 파란 "Windows의 PC 보호" 창
- **[추가 정보] → [실행]**
- 또는 실행하기 전에 설치 파일을 오른쪽 클릭 → **[속성]** → 아래쪽 **[차단 해제]** 체크 → [확인] 하면 이 창이 뜨지 않습니다.

**한 번 설치한 뒤에는** 프로그램 안의 **[도움말 → 업데이트 확인...]** 으로 새 버전을 받으면 이런 경고가 거의 나오지 않습니다.

## RAW 사진

Adobe DNG Converter(무료)를 따로 설치하면 RAW 를 고화질로 엽니다. 없으면 카메라가 넣어 둔 미리보기로 엽니다.
